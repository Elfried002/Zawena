# 1. Objectif

Cette Politique de Confidentialité décrit la manière dont Zawena Platform collecte, utilise, protège et conserve les données personnelles de ses utilisateurs.

Elle vise à garantir une information claire et transparente sur les traitements réalisés.

---

# 2. Champ d'application

Cette politique s'applique :

- aux visiteurs du site web ;
- aux utilisateurs enregistrés ;
- aux clients ;
- aux partenaires utilisant les services de Zawena.

---

# 3. Données collectées

Selon les services utilisés, Zawena peut collecter notamment :

## Données d'identification

- nom ;
- prénom ;
- adresse e-mail ;
- numéro de téléphone ;
- nom de l'entreprise.

---

## Données de connexion

- adresse IP ;
- navigateur ;
- système d'exploitation ;
- journaux de connexion ;
- date et heure des connexions.

---

## Données d'utilisation

- actions réalisées dans la plateforme ;
- préférences utilisateur ;
- paramètres de compte ;
- historique des activités.

---

## Données de facturation

Lorsque applicable :

- informations de facturation ;
- historique des paiements ;
- informations liées aux abonnements.

Les données de paiement sont traitées par les prestataires de paiement concernés conformément à leurs propres politiques.

---

# 4. Finalités du traitement

Les données sont utilisées notamment pour :

- créer et gérer les comptes utilisateurs ;
- fournir les services de Zawena ;
- assurer le support client ;
- améliorer la plateforme ;
- garantir la sécurité ;
- communiquer avec les utilisateurs ;
- respecter les obligations légales ;
- produire des statistiques anonymisées.

---

# 5. Bases légales

Selon la réglementation applicable, les traitements peuvent être fondés sur :

- l'exécution d'un contrat ;
- le consentement de l'utilisateur ;
- les intérêts légitimes de Zawena ;
- le respect d'obligations légales.

La base juridique applicable dépend de la nature du traitement concerné.

---

# 6. Partage des données

Les données peuvent être partagées uniquement lorsque cela est nécessaire avec :

- les prestataires d'hébergement ;
- les fournisseurs d'authentification ;
- les services de messagerie ;
- les prestataires de paiement ;
- les fournisseurs d'analytique ;
- les autorités compétentes lorsque la loi l'exige.

Zawena ne vend pas les données personnelles de ses utilisateurs.

---

# 7. Conservation des données

Les données sont conservées uniquement pendant la durée nécessaire à la réalisation des finalités prévues ou conformément aux obligations légales applicables.

À l'issue de cette période, elles sont :

- supprimées ;
- anonymisées ; ou
- archivées lorsque la réglementation l'impose.

---

# 8. Sécurité

Zawena met en œuvre des mesures techniques et organisationnelles destinées à protéger les données personnelles, notamment :

- contrôle des accès ;
- authentification sécurisée ;
- chiffrement des communications ;
- sauvegardes régulières ;
- journalisation des événements ;
- surveillance de la sécurité.

Malgré ces mesures, aucun système ne peut garantir une sécurité absolue.

---

# 9. Droits des utilisateurs

Selon la législation applicable, les utilisateurs peuvent notamment disposer des droits suivants :

- accéder à leurs données ;
- demander la rectification de données inexactes ;
- demander la suppression de leurs données lorsque cela est possible ;
- demander la limitation de certains traitements ;
- s'opposer à certains traitements ;
- demander la portabilité de leurs données lorsque ce droit est applicable ;
- retirer leur consentement lorsque le traitement repose sur celui-ci.

Les demandes sont examinées dans les délais prévus par la réglementation applicable.

---

# 10. Cookies et technologies similaires

Zawena utilise des cookies et technologies similaires pour :

- assurer le fonctionnement de la plateforme ;
- mémoriser certaines préférences ;
- mesurer l'utilisation des services ;
- améliorer l'expérience utilisateur.

Les informations détaillées figurent dans la politique relative aux cookies.

---

# 11. Transferts internationaux

Lorsque des prestataires situés dans d'autres pays sont utilisés, Zawena s'assure que des garanties appropriées sont mises en place conformément aux exigences légales applicables.

---

# 12. Modifications de la politique

Cette politique peut être mise à jour afin de tenir compte :

- des évolutions du produit ;
- des évolutions réglementaires ;
- des nouveaux traitements mis en œuvre.

La version en vigueur est celle publiée sur la plateforme.

---

# 13. Contact

Toute demande relative à la protection des données peut être adressée à l'équipe Zawena via les canaux officiels de contact.

Les coordonnées sont publiées sur le site officiel de la plateforme.
