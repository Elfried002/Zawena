# 1. Objectif

Le présent Master Service Agreement (MSA) établit les conditions générales applicables à l'ensemble des prestations réalisées entre Zawena Platform et le client.

Son objectif est de créer un cadre contractuel durable permettant d'éviter de renégocier les clauses générales pour chaque nouveau projet.

---

# 2. Portée

Le présent MSA peut couvrir notamment :

- abonnement SaaS ;
- développement spécifique ;
- intégration ;
- maintenance ;
- formation ;
- assistance ;
- conseil ;
- évolutions applicatives.

Les prestations détaillées sont définies dans les devis, bons de commande ou Statements of Work (SOW) associés.

---

# 3. Définitions

Les termes utilisés dans le présent document sont définis dans les Conditions d'Utilisation ainsi que dans les documents contractuels associés.

Les définitions spécifiques à une prestation peuvent être précisées dans un SOW.

---

# 4. Objet du MSA

Le présent accord fixe les règles générales concernant :

- les prestations ;
- les responsabilités ;
- les paiements ;
- la propriété intellectuelle ;
- la confidentialité ;
- la sécurité ;
- la gouvernance des projets.

---

# 5. Prestations couvertes

Les prestations peuvent inclure notamment :

- accès à Zawena Platform ;
- hébergement des services ;
- maintenance ;
- support ;
- accompagnement ;
- développement personnalisé ;
- intégration avec des services tiers ;
- formation des utilisateurs.

Chaque prestation est décrite dans un document contractuel spécifique.

---

# 6. Obligations des parties

## Obligations de Zawena

Zawena s'engage notamment à :

- fournir les prestations convenues ;
- maintenir un niveau de qualité conforme aux engagements ;
- protéger les données confiées ;
- assurer le support prévu au contrat ;
- informer le client des évolutions majeures.

---

## Obligations du client

Le client s'engage notamment à :

- fournir les informations nécessaires ;
- respecter les conditions d'utilisation ;
- régler les sommes dues dans les délais convenus ;
- désigner un interlocuteur principal ;
- collaborer avec les équipes projet.

---

# 7. Niveaux de service

Les engagements relatifs :

- à la disponibilité ;
- aux délais d'intervention ;
- aux délais de résolution ;
- aux priorités de support,

sont définis dans le document :

`docs/operations/sla-policy.md`

---

# 8. Sécurité et confidentialité

Zawena applique des mesures de sécurité conformes à ses politiques internes.

Les parties s'engagent à respecter les obligations de confidentialité définies dans :

- NDA Template ;
- Privacy Policy ;
- Security Policy.

---

# 9. Protection des données

Chaque partie respecte les obligations qui lui incombent en matière de protection des données personnelles conformément à la réglementation applicable.

Les traitements réalisés sont décrits dans la Privacy Policy.

---

# 10. Propriété intellectuelle

Sauf disposition contraire prévue dans un contrat spécifique :

- Zawena conserve la propriété de sa plateforme, de ses composants et de sa documentation ;
- le client conserve la propriété de ses données, contenus et documents.

Les développements spécifiques peuvent faire l'objet de clauses particulières.

---

# 11. Facturation et paiements

Les modalités de facturation sont définies dans :

- le devis ;
- le bon de commande ;
- le contrat spécifique.

Le MSA fixe uniquement les règles générales applicables.

---

# 12. Gestion des changements

Toute évolution importante du périmètre des prestations suit le processus de gestion des changements défini par Zawena.

Les modifications peuvent donner lieu à :

- un avenant ;
- un nouveau devis ;
- un nouveau Statement of Work.

---

# 13. Garanties

Zawena fournit les prestations avec un niveau raisonnable de compétence et de diligence.

Sauf disposition contraire prévue au contrat, aucune garantie implicite supplémentaire n'est accordée au-delà de celles imposées par la loi applicable.

---

# 14. Limitation de responsabilité

La responsabilité de chaque partie est limitée dans les conditions prévues par le contrat et la législation applicable.

Aucune disposition du présent document ne limite une responsabilité qui ne peut légalement être exclue.

---

# 15. Durée et résiliation

Le présent accord prend effet à compter de sa signature.

Il demeure applicable jusqu'à sa résiliation conformément aux modalités prévues dans les documents contractuels.

La résiliation d'un projet n'entraîne pas nécessairement la résiliation du MSA, sauf disposition contraire.

---

# 16. Force majeure

Aucune partie ne peut être tenue responsable d'un retard ou d'une inexécution résultant d'un événement de force majeure reconnu par la législation applicable.

La partie concernée informe l'autre partie dans les meilleurs délais.

---

# 17. Droit applicable

Le présent modèle est destiné à être adapté à la juridiction choisie par les parties avant signature.

Le contrat définitif précise :

- le droit applicable ;
- la juridiction compétente ;
- les modalités de résolution des litiges.

---

# 18. Signature

Le document définitif comporte notamment :

- identification des parties ;
- représentants habilités ;
- date de signature ;
- signatures ;
- annexes éventuelles.

---

# 19. Bonnes pratiques

✔ Utiliser le MSA comme contrat-cadre.

✔ Définir chaque projet dans un SOW ou un devis.

✔ Conserver un historique des avenants.

✔ Vérifier la cohérence avec les politiques internes.

✔ Réviser le MSA lors d'une évolution importante des offres.
