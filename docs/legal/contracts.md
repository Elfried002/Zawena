# 1. Objectif

Ce document définit les principes de gestion des contrats conclus entre Zawena Platform et ses clients, partenaires ou prestataires.

Les objectifs sont :

- standardiser les engagements contractuels ;
- réduire les risques juridiques ;
- assurer une traçabilité complète des contrats ;
- faciliter le suivi du cycle de vie contractuel.

---

# 2. Portée

Cette politique s'applique à tous les contrats liés aux activités de Zawena, notamment :

- abonnements SaaS ;
- prestations de développement ;
- maintenance ;
- accompagnement et conseil ;
- partenariats ;
- sous-traitance.

---

# 3. Principes

Chaque contrat doit être :

- rédigé de manière claire ;
- validé avant signature ;
- conforme aux politiques internes ;
- conservé de manière sécurisée ;
- facilement traçable.

Aucun service ne doit être fourni sans cadre contractuel approprié, sauf décision exceptionnelle validée par la direction.

---

# 4. Types de contrats

## Contrat d'abonnement SaaS

Définit les conditions d'accès à la plateforme.

Contient notamment :

- offre souscrite ;
- durée ;
- prix ;
- modalités de paiement ;
- services inclus.

---

## Contrat de prestation

Utilisé pour :

- développement spécifique ;
- intégration ;
- accompagnement ;
- formation.

---

## Contrat de maintenance

Décrit :

- les services couverts ;
- les niveaux de support ;
- les délais d'intervention ;
- les modalités de renouvellement.

---

## Contrat de partenariat

Détermine :

- les responsabilités des parties ;
- les objectifs communs ;
- les modalités de collaboration.

---

## Contrat de sous-traitance

Encadre les prestations réalisées par un prestataire externe.

# 5. Cycle de vie d'un contrat

Chaque contrat suit le processus suivant :

```text
Préparation

↓

Rédaction

↓

Relecture

↓

Validation

↓

Signature

↓

Exécution

↓

Suivi

↓

Renouvellement ou Résiliation

↓

Archivage
```

---

# 6. Contenu minimal d'un contrat

Chaque contrat doit préciser au minimum :

- l'identité des parties ;
- l'objet du contrat ;
- le périmètre des prestations ;
- les responsabilités de chaque partie ;
- les conditions financières ;
- les modalités de paiement ;
- la durée ;
- les conditions de renouvellement ;
- les conditions de résiliation ;
- les règles de confidentialité ;
- la propriété intellectuelle ;
- le droit applicable ;
- le règlement des litiges.

---

# 7. Gestion des modifications

Toute modification contractuelle doit :

- être documentée ;
- être approuvée par les parties concernées ;
- faire l'objet d'un avenant ou d'une nouvelle version du contrat.

Les anciennes versions sont conservées à des fins d'historique.

---

# 8. Renouvellement

Les contrats peuvent être :

- renouvelés automatiquement si cela est prévu ;
- renouvelés après accord des parties ;
- remplacés par un nouveau contrat.

Les modalités de renouvellement sont précisées dans chaque contrat.

---

# 9. Suspension et résiliation

Un contrat peut être suspendu ou résilié notamment en cas de :

- non-respect des obligations contractuelles ;
- défaut de paiement ;
- accord entre les parties ;
- force majeure lorsque cela est prévu.

Les modalités exactes sont définies dans chaque contrat.

---

# 10. Archivage

Les contrats signés sont :

- archivés de manière sécurisée ;
- accessibles uniquement aux personnes autorisées ;
- conservés conformément aux obligations légales et aux politiques internes de conservation.

---

# 11. Bonnes pratiques

✔ Utiliser des modèles de contrats validés.

✔ Vérifier l'identité des parties.

✔ Définir précisément le périmètre des prestations.

✔ Versionner les contrats.

✔ Conserver toutes les signatures et annexes.

✔ Assurer un suivi des échéances importantes.

---

# 12. Anti-patterns

✘ Fournir une prestation sans contrat.

✘ Modifier un contrat oralement sans trace écrite.

✘ Utiliser un modèle obsolète.

✘ Oublier les modalités de résiliation.

✘ Perdre l'historique des versions.

---

# 13. Révision

Cette politique est revue :

- après une évolution réglementaire majeure ;
- après une évolution des offres commerciales ;
- au minimum une fois par an.
