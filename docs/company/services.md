# 1. Objectif

Ce document présente l'ensemble des services proposés par Zawena.

Il constitue la référence officielle utilisée pour :

- le site internet ;
- les propositions commerciales ;
- les présentations de l'entreprise ;
- les supports marketing ;
- les futures équipes commerciales.

Tous les services sont conçus pour répondre à des problématiques métier concrètes.

---

# 2. Philosophie des services

Chez Zawena, nous ne vendons pas des technologies.

Nous vendons des solutions.

Chaque intervention commence toujours par la compréhension du besoin du client avant toute proposition technique.

Notre objectif est de construire une relation durable et de créer une valeur mesurable.

Nous concevons des agents intelligents capables d'automatiser des tâches, d'assister les collaborateurs ou d'améliorer la relation client.

### Cas d'usage

- Assistant Service Client
- Agent Commercial
- Assistant RH
- Support interne
- Recherche documentaire
- FAQ intelligente
- Agent WhatsApp
- Agent Email

### Bénéfices

- disponibilité 24h/24
- réduction du temps de traitement
- amélioration de l'expérience client
- automatisation des réponses
- assistance aux équipes
