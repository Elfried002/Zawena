# 1. Objectif

Ce document décrit l'ensemble des services proposés par Zawena Platform.

Il permet de :

- définir clairement les services disponibles ;
- préciser les responsabilités associées ;
- faciliter la communication avec les clients ;
- standardiser les opérations de support.

---

# 2. Portée

Le catalogue couvre :

- les services SaaS ;
- les services d'administration ;
- les services de support ;
- les services liés aux données ;
- les services techniques.

---

# 3. Catégories de services

Les services sont répartis selon les catégories suivantes :

- Services applicatifs
- Services de gestion
- Services techniques
- Services de support
- Services d'administration
