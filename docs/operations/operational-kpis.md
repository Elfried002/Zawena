# 1. Objectif

Ce document définit les principaux indicateurs de performance opérationnelle (KPI) utilisés pour mesurer l'efficacité des opérations de Zawena Platform.

Les objectifs sont :

- mesurer la qualité des opérations ;
- suivre les performances ;
- détecter les axes d'amélioration ;
- faciliter la prise de décision.

---

# 2. Portée

Les KPI couvrent :

- l'exploitation de la plateforme ;
- le support client ;
- les déploiements ;
- la maintenance ;
- la disponibilité des services ;
- la satisfaction des utilisateurs.

---

# 3. Principes

Chaque KPI doit être :

- mesurable ;
- fiable ;
- compréhensible ;
- suivi régulièrement ;
- exploitable pour l'amélioration continue.

---

# 4. Catégories de KPI

Les indicateurs sont regroupés selon les catégories suivantes :

- Disponibilité
- Support
- Déploiement
- Exploitation
- Satisfaction Client

---

# 5. KPI Disponibilité

| KPI | Objectif | Fréquence |
|------|----------|-----------|
| Disponibilité de la plateforme | ≥ 99,9 % | Mensuelle |
| Disponibilité des API | ≥ 99,9 % | Mensuelle |
| Disponibilité de l'authentification | ≥ 99,9 % | Mensuelle |
| Temps d'indisponibilité | < 45 min / mois | Mensuelle |

---

# 6. KPI Support

| KPI | Objectif | Fréquence |
|------|----------|-----------|
| Temps moyen de première réponse (MTTA) | < 1 heure | Mensuelle |
| Temps moyen de résolution (MTTR) | < 4 heures | Mensuelle |
| Tickets résolus dans le SLA | ≥ 95 % | Mensuelle |
| Tickets réouverts | < 5 % | Mensuelle |

---

# 7. KPI Déploiement

| KPI | Objectif | Fréquence |
|------|----------|-----------|
| Déploiements réussis | ≥ 98 % | Mensuelle |
| Déploiements annulés | < 2 % | Mensuelle |
| Rollbacks | < 2 % | Mensuelle |
| Temps moyen de déploiement | < 15 min | Mensuelle |

---

# 8. KPI Exploitation

| KPI | Objectif | Fréquence |
|------|----------|-----------|
| Sauvegardes réussies | 100 % | Quotidienne |
| Tests de restauration réussis | 100 % | Trimestrielle |
| Changements réalisés sans incident | ≥ 95 % | Mensuelle |
| Runbooks mis à jour | 100 % | Semestrielle |

---

# 9. KPI Satisfaction Client

| KPI | Objectif | Fréquence |
|------|----------|-----------|
| Satisfaction client (CSAT) | ≥ 90 % | Trimestrielle |
| Temps moyen de traitement des demandes | < 2 jours ouvrés | Mensuelle |
| Réclamations critiques | 0 | Mensuelle |
| Taux de renouvellement des abonnements | ≥ 90 % | Annuelle |

# 11. Révision

Les KPI sont revus :

- chaque trimestre ;
- après une évolution majeure des opérations ;
- après une révision des SLA.
