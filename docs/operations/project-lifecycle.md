# 1. Objectif

Ce document décrit le cycle de vie standard des projets réalisés avec Zawena Platform.

Les objectifs sont :

- standardiser la gestion des projets ;
- améliorer la visibilité ;
- garantir la qualité des livrables ;
- faciliter le suivi client ;
- assurer une livraison maîtrisée.

---

# 2. Portée

Cette procédure s'applique à tous les projets réalisés via Zawena, notamment :

- création de sites web ;
- développement d'applications web ;
- développement SaaS ;
- maintenance évolutive ;
- prestations techniques.

---

# 3. Principes

Chaque projet suit un processus unique.

Les principes sont :

- transparence ;
- traçabilité ;
- collaboration ;
- qualité ;
- amélioration continue.

Chaque étape doit être validée avant le passage à la suivante.

---

# 4. Cycle de vie d'un projet

Tous les projets suivent le cycle suivant :

```text
Prospect

↓

Qualification

↓

Devis

↓

Validation

↓

Planification

↓

Exécution

↓

Recette

↓

Livraison

↓

Support

↓

Maintenance

↓

Clôture
```

---

# 5. Description des phases

## 5.1 Qualification

Objectif :

Comprendre le besoin du client.

Activités :

- analyse du besoin ;
- collecte des informations ;
- définition des objectifs.

Livrable :

Dossier de qualification.

---

## 5.2 Devis

Objectif :

Formaliser la proposition commerciale.

Activités :

- estimation ;
- rédaction du devis ;
- validation interne.

Livrable :

Devis.

---

## 5.3 Validation

Objectif :

Obtenir l'accord du client.

Activités :

- signature ;
- paiement éventuel de l'acompte ;
- ouverture officielle du projet.

Livrable :

Projet créé.

---

## 5.4 Planification

Objectif :

Organiser le projet.

Activités :

- création des tâches ;
- affectation des ressources ;
- planification.

Livrable :

Planning projet.

---

## 5.5 Exécution

Objectif :

Produire les livrables.

Activités :

- développement ;
- design ;
- tests ;
- suivi.

Livrable :

Version prête pour recette.

---

## 5.6 Recette

Objectif :

Valider les livrables.

Activités :

- tests internes ;
- tests client ;
- corrections.

Livrable :

Validation de recette.

---

## 5.7 Livraison

Objectif :

Mettre le projet à disposition du client.

Activités :

- déploiement ;
- transfert ;
- documentation.

Livrable :

Projet livré.

---

## 5.8 Support

Objectif :

Assister le client après la livraison.

Activités :

- assistance ;
- corrections ;
- réponses aux demandes.

---

## 5.9 Maintenance

Objectif :

Faire évoluer le projet.

Activités :

- correctifs ;
- mises à jour ;
- améliorations.

---

## 5.10 Clôture

Objectif :

Finaliser officiellement le projet.

Activités :

- validation finale ;
- archivage ;
- retour d'expérience.

# 8. Critères de passage

Une phase ne peut être clôturée que si :

- les livrables sont terminés ;
- les validations sont obtenues ;
- les documents sont complétés ;
- les tâches sont clôturées.

---

# 9. Clôture du projet

Avant la clôture :

- toutes les tâches sont terminées ;
- la documentation est livrée ;
- le client valide le projet ;
- les livrables sont archivés ;
- un retour d'expérience est réalisé.

---

# 10. Bonnes pratiques

✔ Définir clairement les objectifs.

✔ Communiquer régulièrement avec le client.

✔ Valider chaque phase.

✔ Mettre à jour l'avancement.

✔ Documenter les décisions importantes.

✔ Planifier les risques.

---

# 11. Anti-patterns

✘ Commencer sans qualification.

✘ Modifier constamment le périmètre.

✘ Livrer sans recette.

✘ Oublier la documentation.

✘ Clôturer sans validation client.
