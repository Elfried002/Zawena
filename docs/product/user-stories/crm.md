# 1. Objectif

Ce document décrit l'ensemble des User Stories du module CRM.

Le CRM permet de gérer les prospects, entreprises, contacts, opportunités commerciales et l'ensemble du pipeline de vente jusqu'à la création d'un projet.

---

# 2. Vue d'ensemble

Le CRM est organisé autour des objets métier suivants :

- Leads
- Prospects
- Entreprises
- Contacts
- Opportunités
- Activités
- Notes
- Devis
