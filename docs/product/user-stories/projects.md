# 1. Objectif

Ce document décrit les User Stories du module Projects.

Le module Projects permet de planifier, organiser, exécuter, suivre et clôturer les projets réalisés par Zawena pour ses clients.

## US-PROJ-001 — Créer un projet

En tant que Project Manager

Je veux créer un nouveau projet

Afin de démarrer une nouvelle prestation.

Critères d'acceptation :

- Projet créé.
- Client associé.
- Chef de projet défini.
- Statut initial "Brouillon".
