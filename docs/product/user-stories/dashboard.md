# 1. Objectif

Ce document décrit les User Stories du Dashboard de Zawena Platform.

Le Dashboard constitue le point d'entrée principal après authentification et fournit une vue synthétique des activités, indicateurs et actions prioritaires selon le rôle de l'utilisateur.

---

# 2. Vue d'ensemble

Le Dashboard permet à chaque utilisateur de :

- consulter les indicateurs clés ;
- accéder rapidement aux modules ;
- visualiser les activités récentes ;
- recevoir les notifications importantes ;
- suivre les tâches prioritaires.

Le contenu du Dashboard varie selon le rôle de l'utilisateur.

# 5. User Stories

---

# US-DASH-001 — Accéder au Dashboard

## Priorité

Must Have

## En tant que

Utilisateur authentifié

## Je veux

Accéder à mon Dashboard.

## Afin de

Retrouver rapidement toutes les informations importantes.

### Critères d'acceptation

- Chargement réussi après connexion.
- Tableau de bord correspondant au rôle.
- Temps de chargement conforme.

---

# US-DASH-002 — Consulter les informations de bienvenue

## En tant que

Utilisateur

## Je veux

Voir un message de bienvenue personnalisé.

## Afin de

Confirmer que je suis connecté avec le bon compte.

### Critères d'acceptation

- Nom affiché.
- Photo de profil affichée si disponible.
- Date et heure correctement affichées.

---

# US-DASH-003 — Accéder rapidement aux modules

## En tant que

Utilisateur

## Je veux

Accéder rapidement aux principaux modules.

## Afin de

Réduire le nombre de clics.

### Critères d'acceptation

- Raccourcis visibles.
- Respect des permissions.
- Navigation fonctionnelle.
