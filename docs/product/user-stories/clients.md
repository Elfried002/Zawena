# 1. Objectif

Ce document décrit les User Stories du module Client Portal.

Le portail client offre un espace sécurisé permettant aux clients de suivre leurs projets, consulter leurs documents, accéder à leurs devis, contrats et notifications.

---

# 2. Vue d'ensemble

Le portail client permet :

- consulter les projets ;
- suivre l'avancement ;
- consulter les devis ;
- consulter les contrats ;
- télécharger les documents ;
- gérer son profil ;
- consulter les notifications.

# Epic 1 — Dashboard Client

## US-CLIENT-001 — Accéder au portail client

En tant que Client

Je veux accéder à mon portail sécurisé

Afin de consulter les informations liées à mes prestations.

Critères d'acceptation

- Authentification obligatoire.
- Dashboard chargé.
- Données limitées à mon organisation.
