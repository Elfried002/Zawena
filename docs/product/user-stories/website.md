# 1. Objectif

Ce document décrit l'ensemble des User Stories du module Website.

Il constitue le backlog fonctionnel du site public de Zawena.

Toutes les stories décrites dans ce document sont directement liées à la Feature Specification :

docs/product/features/01-website.md

---

# 2. Vue d'ensemble

Le Website constitue le principal point d'entrée de Zawena.

Les visiteurs doivent pouvoir :

- découvrir Zawena ;
- comprendre les services ;
- consulter les réalisations ;
- lire les contenus ;
- contacter l'entreprise ;
- demander un devis.

# US-WEB-001 — Consulter la page d'accueil

## Priorité

Must Have

## En tant que

Visiteur

## Je veux

Consulter la page d'accueil.

## Afin de

Comprendre rapidement ce que propose Zawena.

### Critères d'acceptation

- Hero visible.
- Proposition de valeur affichée.
- CTA visibles.
- Responsive.
- Temps de chargement conforme.

---

# US-WEB-002 — Naviguer entre les pages

## En tant que

Visiteur

## Je veux

Naviguer facilement entre les différentes pages du site.

## Afin de

Découvrir les informations qui m'intéressent.

### Critères d'acceptation

- Navigation accessible.
- Liens fonctionnels.
- Menu actif visible.
