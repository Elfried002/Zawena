# 1. Objectif

Ce document décrit l'évolution planifiée de Zawena Platform.

Il permet de :

- communiquer la vision du produit ;
- prioriser les développements ;
- organiser les versions ;
- planifier les investissements ;
- préparer les futures évolutions.

---

# 2. Vision produit

Zawena a pour ambition de devenir une plateforme SaaS complète permettant aux agences digitales, ESN et cabinets de conseil de gérer l'ensemble de leur activité depuis une seule interface.

À long terme, la plateforme intégrera des fonctionnalités avancées d'intelligence artificielle, d'automatisation, de collaboration temps réel et d'analyse décisionnelle.

---

# 3. Principes de la roadmap

La roadmap suit les principes suivants :

- priorité à la valeur métier ;
- livraison incrémentale ;
- amélioration continue ;
- compatibilité ascendante ;
- évolutivité de l'architecture ;
- limitation du périmètre de chaque version.

---

# 4. MVP

## Objectif

Mettre en production une première version exploitable par des clients réels.

### Modules inclus

- Website
- Authentication
- Dashboard
- CRM
- Quotes
- Projects
- Client Portal
- CMS
- Notifications
- Settings

### Objectifs

- obtenir les premiers utilisateurs ;
- valider le modèle métier ;
- recueillir les retours terrain ;
- stabiliser l'architecture.

# 10. Critères de priorisation

Chaque fonctionnalité est évaluée selon :

- valeur métier ;
- impact utilisateur ;
- complexité technique ;
- coût de développement ;
- dépendances ;
- retour sur investissement (ROI).

Les développements sont priorisés selon la matrice :

- Impact élevé / Effort faible → Priorité 1
- Impact élevé / Effort élevé → Priorité 2
- Impact faible / Effort faible → Priorité 3
- Impact faible / Effort élevé → À reconsidérer

# 11. Indicateurs de succès

La progression de la roadmap sera évaluée à l'aide de :

## Produit

- Pourcentage de fonctionnalités livrées
- Nombre de versions publiées
- Respect des jalons

## Qualité

- Nombre de bugs critiques
- Couverture des tests
- Disponibilité de la plateforme

## Utilisation

- Nombre d'organisations clientes
- Nombre d'utilisateurs actifs
- Taux d'utilisation des modules

## Satisfaction

- Satisfaction client
- Taux de rétention
- Nombre de demandes d'évolution
