# 1. Objectif

Le Chef de Projet est responsable de la planification, de l'exécution et du suivi des projets clients.

Il assure la coordination entre les équipes internes, les clients et les partenaires afin de garantir la qualité, les délais et le respect du budget.

# 3. Profil

Le Chef de Projet possède :

- des compétences organisationnelles ;
- une bonne communication ;
- une compréhension des métiers de Zawena ;
- une capacité à coordonner plusieurs équipes.

Il travaille quotidiennement avec :

- les commerciaux ;
- les développeurs ;
- les clients ;
- les partenaires.

---

# 4. Responsabilités

Le Chef de Projet est responsable de :

- créer les projets ;
- planifier les tâches ;
- organiser les jalons ;
- attribuer les missions ;
- suivre l'avancement ;
- gérer les risques ;
- organiser les réunions ;
- communiquer avec les clients ;
- valider les livrables ;
- clôturer les projets.

---

# 5. Objectifs métier

Ses objectifs sont :

- respecter les délais ;
- respecter le budget ;
- maintenir une communication fluide ;
- assurer la qualité des livrables ;
- garantir la satisfaction client.

---

# 12. Permissions

Le Chef de Projet peut :

✓ créer des projets ;

✓ gérer les tâches ;

✓ consulter les clients liés à ses projets ;

✓ partager des documents ;

✓ consulter les rapports de projet ;

✓ communiquer avec les équipes.

---

# 13. Restrictions

Le Chef de Projet ne peut pas :

✗ gérer les utilisateurs ;

✗ modifier les paramètres système ;

✗ accéder aux paramètres de sécurité ;

✗ supprimer définitivement un projet ;

✗ modifier les permissions.
