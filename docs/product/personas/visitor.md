# 1. Objectif

Ce document décrit le persona "Visiteur".

Le visiteur représente toute personne consultant le site internet de Zawena sans disposer d'un compte utilisateur.

L'objectif principal est de comprendre ses attentes afin de concevoir un site capable de transformer un simple visiteur en prospect qualifié.

---

# 2. Présentation

Nom du persona :

Visitor

---

Type

Utilisateur externe

---

Authentification

Aucune

---

Niveau d'accès

Public

---

Objectif principal

Découvrir Zawena.

Comprendre les services proposés.

Évaluer la crédibilité de l'entreprise.

Entrer en contact.

---

# 3. Profil

Le visiteur peut être :

- un dirigeant d'entreprise ;
- un responsable informatique ;
- un chef de projet ;
- un entrepreneur ;
- une startup ;
- une PME ;
- une grande entreprise ;
- une administration ;
- une ONG.

Il connaît généralement un problème mais ne sait pas encore quelle solution choisir.

---

# 4. Contexte

Le visiteur arrive généralement depuis :

- Google
- LinkedIn
- Facebook
- une recommandation
- une carte de visite
- un email
- un QR Code
- une publicité
- un partenaire

Il dispose de peu de temps.

Les premières secondes sont déterminantes.

---

# 5. Objectifs

Le visiteur souhaite rapidement savoir :

Qui est Zawena ?

Quels services sont proposés ?

Quels problèmes sont résolus ?

Pourquoi faire confiance à Zawena ?

Comment prendre contact ?

Quel est le coût approximatif ?

Quels sont les projets réalisés ?

---

# 6. Motivations

Le visiteur souhaite :

- gagner du temps ;
- trouver un partenaire fiable ;
- moderniser son entreprise ;
- automatiser certaines tâches ;
- utiliser l'Intelligence Artificielle ;
- sécuriser son système d'information.

---

# 7. Frustrations

Le visiteur quitte généralement un site lorsque :

- les informations sont floues ;
- le design manque de professionnalisme ;
- le site est lent ;
- les services sont mal expliqués ;
- il est difficile de contacter l'entreprise ;
- aucune preuve de crédibilité n'est visible.

---

# 8. Besoins

Le visiteur attend :

- une présentation claire ;
- des exemples concrets ;
- des études de cas ;
- des témoignages ;
- des appels à l'action visibles ;
- une navigation intuitive ;
- une compatibilité mobile.

---

# 10. Fonctionnalités utilisées

Le visiteur peut accéder à :

- Accueil
- Services
- À propos
- Réalisations
- Blog
- FAQ
- Contact
- Demande de devis

Il ne peut accéder à aucun espace privé.

---

# 11. Permissions

Le visiteur peut :

✓ Consulter les pages publiques.

✓ Lire les articles.

✓ Utiliser le formulaire de contact.

✓ Demander un devis.

✓ Consulter les mentions légales.

---

Le visiteur ne peut pas :

✗ Accéder au CRM.

✗ Accéder au Dashboard.

✗ Modifier des contenus.

✗ Voir les informations des clients.

✗ Consulter les projets.

---

# 12. Indicateurs de réussite

Nous considérons que l'expérience du visiteur est réussie lorsqu'il :

- reste suffisamment longtemps sur le site ;
- consulte plusieurs pages ;
- comprend les services proposés ;
- remplit un formulaire ;
- demande un devis ;
- prend rendez-vous.
