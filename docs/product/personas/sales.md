# 1. Objectif

Le Commercial est responsable du développement commercial de Zawena.

Son rôle consiste à identifier des opportunités, qualifier les prospects, préparer les propositions commerciales et accompagner les prospects jusqu'à la signature.

Le Commercial est le principal utilisateur du CRM.

# 3. Profil

Le Commercial possède :

- une excellente communication ;
- une bonne compréhension des services Zawena ;
- une capacité d'écoute ;
- une orientation résultats.

Il travaille en collaboration avec les chefs de projet et les administrateurs.

---

# 4. Responsabilités

Le Commercial est responsable de :

- qualifier les prospects ;
- planifier les rendez-vous ;
- préparer les devis ;
- assurer le suivi commercial ;
- mettre à jour le CRM ;
- relancer les prospects ;
- négocier les propositions commerciales ;
- transmettre les projets signés.

---

# 5. Objectifs métier

Le Commercial cherche à :

- augmenter le nombre de contrats signés ;
- améliorer le taux de conversion ;
- réduire le cycle de vente ;
- fidéliser les clients ;
- maintenir un CRM à jour.

# 9. Actions principales

Le Commercial peut :

- créer un prospect ;
- modifier une fiche prospect ;
- planifier une réunion ;
- générer un devis ;
- envoyer une proposition commerciale ;
- changer le statut d'une opportunité ;
- clôturer une opportunité (gagnée ou perdue).

---

# 10. Permissions

Le Commercial peut :

✓ créer des prospects ;

✓ modifier les prospects dont il est responsable ;

✓ consulter les devis ;

✓ créer des devis ;

✓ consulter les contrats qui lui sont attribués ;

✓ accéder aux rapports commerciaux.

---

Il ne peut pas :

✗ supprimer un client ;

✗ modifier les paramètres système ;

✗ gérer les utilisateurs ;

✗ accéder aux données de sécurité.

---

# 11. Restrictions

Le Commercial ne peut pas :

- modifier les permissions ;
- supprimer définitivement des données ;
- clôturer un projet ;
- publier du contenu sur le site.

# 13. KPIs

Les principaux indicateurs sont :

- nombre de prospects qualifiés ;
- taux de conversion ;
- chiffre d'affaires généré ;
- valeur moyenne des contrats ;
- durée moyenne du cycle de vente ;
- taux de relance.

---

# 14. Risques

Une mauvaise gestion commerciale peut entraîner :

- perte d'opportunités ;
- devis erronés ;
- mauvaise qualification ;
- insatisfaction du prospect.

---

# 15. Journalisation

Les actions enregistrées incluent :

- création de prospect ;
- modification de prospect ;
- changement de statut ;
- génération de devis ;
- envoi d'une proposition ;
- planification d'un rendez-vous.

---

# 16. Interactions avec les Agents IA

Le Commercial pourra utiliser un Agent IA pour :

- qualifier automatiquement les prospects ;
- générer un premier devis ;
- rédiger des emails ;
- préparer un compte rendu de réunion ;
- résumer les échanges ;
- identifier les prospects prioritaires ;
- proposer les prochaines actions.

Toutes les décisions commerciales restent validées par un humain.

- les prospects sont correctement qualifiés ;
- les devis sont envoyés rapidement ;
- les opportunités progressent dans le pipeline ;
- les contrats sont signés ;
- les informations du CRM sont fiables et à jour.
