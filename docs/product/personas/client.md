# 1. Objectif

Le Client représente une entreprise ou un particulier ayant signé un contrat avec Zawena.

Il utilise la plateforme afin de suivre ses projets, communiquer avec les équipes de Zawena et accéder aux différents services proposés.

L'objectif est d'offrir une expérience simple, transparente et professionnelle tout au long de la collaboration.

# 3. Profil

Le client peut être :

- une startup ;
- une PME ;
- une grande entreprise ;
- une administration publique ;
- une ONG ;
- un entrepreneur.

Le compte client peut être utilisé par un ou plusieurs collaborateurs selon les permissions accordées.

---

# 4. Contexte

Le client a choisi Zawena pour résoudre un besoin métier.

Il souhaite désormais :

- suivre l'avancement de ses projets ;
- communiquer efficacement avec Zawena ;
- accéder rapidement à ses documents ;
- disposer d'une visibilité sur les prochaines étapes.

---

# 5. Objectifs métier

Le client souhaite :

- gagner du temps ;
- suivre l'évolution des projets ;
- centraliser les échanges ;
- accéder à ses documents ;
- connaître les échéances ;
- sécuriser ses données.

---

# 6. Motivations

Le client recherche :

- une relation de confiance ;
- de la transparence ;
- de la réactivité ;
- des livraisons de qualité ;
- un partenaire capable d'accompagner sa croissance.

---

# 7. Comportements

Le client :

- consulte régulièrement les projets ;
- télécharge des documents ;
- répond aux demandes d'information ;
- échange avec les équipes ;
- valide certaines étapes du projet.

---

# 8. Frustrations

Le client est frustré lorsque :

- il ne sait pas où en est son projet ;
- les délais ne sont pas communiqués ;
- les documents sont difficiles à retrouver ;
- les échanges sont dispersés ;
- il doit relancer plusieurs fois pour obtenir une réponse.

---

# 9. Points de douleur

Les principaux problèmes rencontrés sont :

- manque de visibilité ;
- communication fragmentée ;
- absence de suivi en temps réel ;
- documents dispersés ;
- difficulté à identifier le prochain livrable.

---

# 10. Besoins

Le client attend :

- un tableau de bord clair ;
- une chronologie des projets ;
- un historique des échanges ;
- un espace documentaire sécurisé ;
- des notifications pertinentes ;
- une plateforme disponible à tout moment.

# 13. Fonctionnalités utilisées

Le client peut :

- consulter ses projets ;
- suivre les jalons ;
- télécharger des documents ;
- envoyer des messages ;
- consulter les devis ;
- consulter les contrats ;
- mettre à jour certaines informations de son profil ;
- recevoir des notifications.

---

# 14. Tableau de bord

Le tableau de bord présente notamment :

- projets actifs ;
- prochaines échéances ;
- documents récents ;
- notifications ;
- demandes en attente ;
- messages récents.

L'objectif est de donner une vision synthétique de la relation avec Zawena.

---

# 15. Permissions

Le client peut :

✓ Consulter ses propres données.

✓ Télécharger ses documents.

✓ Consulter ses contrats.

✓ Consulter ses devis.

✓ Communiquer avec Zawena.

✓ Modifier son profil.

---

Le client ne peut pas :

✗ Accéder aux autres clients.

✗ Modifier les données internes.

✗ Accéder au CRM.

✗ Administrer la plateforme.

---

# 16. Notifications

Le client reçoit notamment des notifications lors :

- de la création d'un projet ;
- d'une mise à jour de projet ;
- du partage d'un document ;
- d'une demande de validation ;
- d'un nouveau message ;
- d'une nouvelle facture (versions futures) ;
- d'un renouvellement de contrat.

---

# 17. KPIs

Les principaux indicateurs sont :

- fréquence de connexion ;
- taux d'utilisation de l'espace client ;
- délai moyen de réponse ;
- satisfaction client (CSAT) ;
- Net Promoter Score (NPS) ;
- taux de rétention.

---

# 18. Opportunités d'amélioration

À moyen terme, l'expérience pourra être enrichie grâce à :

- un espace documentaire intelligent ;
- un assistant IA dédié ;
- des tableaux de bord personnalisables ;
- des rapports automatiques ;
- des recommandations d'amélioration.

---

# 19. Interactions avec les Agents IA

Le client pourra interagir avec un agent IA pour :

- obtenir un résumé de l'avancement d'un projet ;
- rechercher un document ;
- répondre aux questions fréquentes ;
- préparer une réunion ;
- expliquer un devis ou un contrat ;
- proposer des optimisations.

L'agent IA ne prend jamais de décision engageant le client sans validation humaine.

# 24. Critères de succès

L'expérience client est considérée comme réussie lorsque :

- le client trouve rapidement les informations recherchées ;
- il suit facilement l'avancement de ses projets ;
- les échanges sont centralisés ;
- les documents sont accessibles en quelques clics ;
- il fait confiance à Zawena comme partenaire de long terme.
