# 1. Objectif

Le prospect représente une personne ou une organisation ayant manifesté un intérêt réel pour les services de Zawena.

Contrairement au visiteur, le prospect a déjà effectué une action concrète :

- demande de devis ;
- prise de rendez-vous ;
- formulaire de contact ;
- échange LinkedIn ;
- appel téléphonique ;
- recommandation.

Le principal objectif de Zawena est de transformer ce prospect en client.

# 3. Profil

Le prospect est généralement :

- Directeur Général
- Fondateur
- Responsable Informatique
- DSI
- Responsable Innovation
- Chef de Projet
- Responsable Digital

Son entreprise compte généralement entre :

- 10 et 500 collaborateurs.

Il dispose d'un budget identifié ou en cours de validation.

---

# 4. Contexte

Le prospect connaît désormais Zawena.

Il cherche à répondre à plusieurs questions.

- Cette entreprise est-elle crédible ?
- Peut-elle résoudre mon problème ?
- Est-elle sérieuse ?
- Quel sera le coût ?
- Quels sont les délais ?
- Quels sont les risques ?

La confiance devient le principal facteur de décision.

---

# 5. Objectifs métier

Le prospect souhaite :

- résoudre un problème concret ;
- réduire ses coûts ;
- améliorer sa productivité ;
- sécuriser son entreprise ;
- intégrer l'IA ;
- trouver un partenaire fiable sur le long terme.

---

# 6. Motivations

Le prospect est motivé par :

- un gain de temps ;
- une amélioration des performances ;
- la modernisation de son entreprise ;
- une meilleure expérience client ;
- la compétitivité.

---

# 7. Comportements

Le prospect :

- compare plusieurs prestataires ;
- consulte les références ;
- lit les études de cas ;
- demande plusieurs devis ;
- pose des questions techniques ;
- implique plusieurs décideurs.

Le cycle de décision peut durer de quelques jours à plusieurs mois.

---

# 8. Frustrations

Le prospect est frustré lorsque :

- les devis sont flous ;
- les délais sont imprécis ;
- les réponses tardent ;
- les prix sont incohérents ;
- les explications sont trop techniques.

---

# 9. Points de douleur

Les principaux problèmes rencontrés sont :

- manque de visibilité ;
- processus manuels ;
- outils dispersés ;
- difficultés d'intégration ;
- manque d'accompagnement ;
- risques de cybersécurité.

---

# 10. Besoins

Le prospect attend :

- un devis clair ;
- une proposition adaptée ;
- des échanges transparents ;
- des démonstrations ;
- une estimation réaliste des délais ;
- des références clients.

# 12. Fonctionnalités utilisées

Le prospect peut :

- demander un devis ;
- consulter les services ;
- prendre rendez-vous ;
- recevoir des propositions ;
- accéder à certains documents partagés.

---

# 13. Permissions

Le prospect peut :

✓ Soumettre un formulaire.

✓ Échanger avec Zawena.

✓ Recevoir un devis.

✓ Consulter les documents qui lui sont partagés.

---

Il ne peut pas :

✗ Modifier les informations internes.

✗ Accéder aux projets.

✗ Accéder au CRM.

✗ Consulter les données d'autres clients.

---

# 14. KPIs

Les principaux indicateurs sont :

- taux de réponse aux devis ;
- délai moyen de qualification ;
- taux de conversion Prospect → Client ;
- valeur moyenne des opportunités ;
- durée du cycle commercial.

---

# 15. Opportunités d'amélioration

Nous pouvons améliorer l'expérience du prospect grâce à :

- un devis interactif ;
- un espace prospect sécurisé ;
- des démonstrations personnalisées ;
- un suivi automatisé ;
- un agent IA capable de répondre aux questions fréquentes.

---

# 16. Interactions avec les Agents IA

À terme, le prospect pourra :

- dialoguer avec un agent commercial IA ;
- obtenir une première estimation budgétaire ;
- planifier un rendez-vous ;
- recevoir des recommandations adaptées à son secteur ;
- suivre l'avancement de sa demande.

Les agents IA ne remplacent pas les échanges humains.

Ils les complètent.

---

# 17. Appareils utilisés

Principalement :

- ordinateur portable ;
- ordinateur de bureau ;
- smartphone.

---

# 18. Contexte d'utilisation

Le prospect consulte généralement Zawena :

- depuis son bureau ;
- pendant ses horaires de travail ;
- lors d'une réunion ;
- pendant une phase d'étude d'un projet.
