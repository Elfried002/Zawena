# 1. Statut

**Accepted**

Cette décision est officiellement adoptée et constitue la référence pour l'ensemble du projet.

---

# 2. Contexte

Le projet nécessitait une identité forte capable d'accompagner sa croissance sur plusieurs années.

Le choix du nom devait répondre à plusieurs objectifs :

- être unique ;
- être mémorisable ;
- être facilement prononçable ;
- être compatible avec une présence internationale ;
- ne pas limiter l'évolution fonctionnelle du produit ;
- permettre la création d'une identité visuelle cohérente.

L'identité de marque devait également refléter les valeurs fondamentales de Zawena : simplicité, confiance, innovation et évolutivité.

---

# 3. Problématique

Comment choisir une identité de marque capable de représenter durablement une plateforme SaaS tout-en-un destinée aux entreprises, tout en restant suffisamment flexible pour accompagner les futures évolutions du produit ?

---

# 4. Facteurs de décision

Les critères retenus sont les suivants :

- simplicité du nom ;
- facilité de mémorisation ;
- disponibilité potentielle du nom de domaine et des réseaux sociaux ;
- neutralité linguistique ;
- identité forte ;
- différenciation vis-à-vis de la concurrence ;
- capacité à devenir une marque internationale.

---

# 5. Options étudiées

## Option A — Nom descriptif

Exemple :

- Business Manager
- Smart ERP
- CRM Africa

### Avantages

- compréhension immédiate ;
- bon référencement initial.

### Inconvénients

- manque d'originalité ;
- difficulté de protection de la marque ;
- risque d'obsolescence si le produit évolue.

---

## Option B — Acronyme

Exemple :

- ZMS
- ZPM
- ZBP

### Avantages

- court ;
- professionnel.

### Inconvénients

- peu mémorable ;
- faible identité émotionnelle ;
- difficile à différencier.

---

## Option C — Marque originale (retenue)

Nom :

**Zawena**

### Avantages

- identité unique ;
- facilement mémorisable ;
- compatible avec une stratégie internationale ;
- adaptable à différents produits et services ;
- forte personnalité de marque.

### Inconvénients

- nécessite un travail de notoriété ;
- la signification doit être construite par la communication de la marque.

---

# 6. Décision

Le nom **Zawena** est retenu comme identité officielle du produit et de la plateforme.

Cette décision repose sur les éléments suivants :

- marque distinctive ;
- image moderne ;
- capacité d'évolution ;
- cohérence avec le positionnement SaaS ;
- facilité d'utilisation dans la communication marketing.

Toutes les communications officielles utilisent désormais cette identité.

---

# 7. Conséquences

### Positives

- identité de marque forte ;
- meilleure différenciation ;
- cohérence entre le produit et la communication ;
- possibilité d'étendre la marque à de nouveaux services.

### Négatives

- investissement marketing nécessaire pour développer la notoriété ;
- nécessité de protéger la marque juridiquement selon les pays ciblés.

---

# 8. Compromis (Trade-offs)

Le choix d'un nom original implique un effort plus important de communication que celui d'un nom descriptif.

En contrepartie, il offre une identité durable et une meilleure différenciation sur le long terme.

---

# 9. Mise en œuvre

Les actions suivantes découlent de cette décision :

- utilisation systématique du nom Zawena sur tous les supports ;
- création de la charte graphique ;
- définition de la voix de la marque ;
- intégration dans la documentation produit ;
- vérification de la disponibilité des domaines et des réseaux sociaux ;
- préparation des démarches de protection de la marque selon les juridictions visées.

---

# 10. Révision

Cette décision est réévaluée uniquement dans les cas suivants :

- changement majeur de stratégie ;
- fusion ou acquisition ;
- contrainte juridique imposant une évolution de la marque.

En dehors de ces situations exceptionnelles, cette décision est considérée comme permanente.
