# 1. Objectif

Ce document définit les règles d'utilisation des photographies au sein de l'identité visuelle de Zawena.

Les photographies doivent renforcer la crédibilité de la marque et illustrer les valeurs de l'entreprise de manière cohérente.

---

# 2. Philosophie photographique

Les photographies utilisées par Zawena doivent transmettre :

- la confiance ;
- l'innovation ;
- la collaboration ;
- l'expertise ;
- la modernité.

Les images doivent mettre en avant les personnes, les technologies et les environnements professionnels.

Nous privilégions toujours des scènes authentiques plutôt que des images artificielles ou excessivement mises en scène.

---

# 3. Style visuel

Les photographies doivent respecter les caractéristiques suivantes :

- haute résolution ;
- éclairage naturel ou maîtrisé ;
- contraste modéré ;
- couleurs cohérentes avec la palette de Zawena ;
- faible saturation excessive ;
- composition épurée.

Le style recherché est professionnel, moderne et intemporel.

# 5. Sujets privilégiés

Les photographies doivent illustrer :

- l'innovation ;
- la collaboration ;
- la transformation numérique ;
- l'Intelligence Artificielle ;
- la cybersécurité ;
- le développement logiciel ;
- l'accompagnement client.

Les scènes doivent rester crédibles et représentatives des activités de Zawena.

---

# 6. Composition

Les photographies doivent privilégier :

- une composition équilibrée ;
- des espaces négatifs pour intégrer du texte ;
- une bonne profondeur de champ lorsque nécessaire ;
- un cadrage mettant en valeur le sujet principal.

Les recadrages ne doivent pas nuire à la lisibilité de l'image.

---

# 7. Palette colorimétrique

Les photographies doivent naturellement s'harmoniser avec :

- le Bleu Zawena ;
- les gris neutres ;
- le blanc ;
- les accents cyan et violet.

Lorsque cela est nécessaire, une légère correction colorimétrique peut être appliquée afin d'assurer une cohérence visuelle.

---

# 8. Utilisation des photographies

Les photographies sont principalement utilisées pour :

- le site internet ;
- les études de cas ;
- les présentations ;
- les publications LinkedIn ;
- les brochures ;
- les rapports ;
- les supports commerciaux.

Chaque photographie doit avoir un objectif de communication clairement identifié.

---

# 9. Photographies interdites

Ne jamais utiliser :

- des images floues ;
- des photographies pixelisées ;
- des visuels fortement retouchés ;
- des images stéréotypées ou trompeuses ;
- des banques d'images génériques sans personnalisation ;
- des photographies incompatibles avec les valeurs de Zawena.

---

# 10. Bonnes pratiques

Toujours :

- privilégier des photographies authentiques ;
- utiliser des images cohérentes avec le message ;
- respecter les droits d'utilisation ;
- conserver une qualité élevée.

Chaque photographie doit renforcer la crédibilité de la marque.
