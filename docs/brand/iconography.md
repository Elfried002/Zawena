# 1. Objectif

Ce document définit les règles d'utilisation des icônes au sein de l'écosystème Zawena.

L'objectif est de garantir une expérience utilisateur cohérente, lisible et professionnelle sur tous les produits.

Toutes les interfaces doivent utiliser une iconographie homogène.

---

# 2. Philosophie de l'iconographie

Les icônes doivent être :

- simples ;
- modernes ;
- reconnaissables ;
- cohérentes ;
- accessibles.

Une icône n'est jamais un élément décoratif.

Elle doit toujours améliorer la compréhension de l'interface.

---

# 3. Bibliothèque d'icônes

La bibliothèque officielle de Zawena est :

## Lucide Icons

Pourquoi ce choix ?

- Open Source
- Léger
- Compatible React
- Compatible Next.js
- Très grande bibliothèque
- Style moderne
- Excellente cohérence graphique

Toutes les nouvelles interfaces doivent utiliser cette bibliothèque en priorité.

Une autre bibliothèque ne peut être utilisée qu'en cas d'absence d'une icône adaptée.

# 9. Utilisation

Les icônes servent principalement à :

- améliorer la compréhension ;
- accélérer la navigation ;
- renforcer la lisibilité.

Une icône importante doit généralement être accompagnée d'un texte.

Éviter les interfaces reposant uniquement sur des icônes.

---

# 10. Bonnes pratiques

Toujours :

- utiliser la même bibliothèque ;
- conserver la même taille dans un même contexte ;
- respecter les couleurs officielles ;
- conserver un espacement cohérent.

Préférer des icônes simples à des illustrations complexes.

---

# 11. Utilisations interdites

Ne jamais :

- mélanger plusieurs bibliothèques d'icônes ;
- modifier arbitrairement l'épaisseur des traits ;
- déformer une icône ;
- utiliser des effets 3D ;
- ajouter des ombres ;
- utiliser des icônes pixelisées ;
- utiliser une icône sans signification claire.
