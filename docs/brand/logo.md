# 1. Objectif

Ce document définit les règles officielles relatives au logo de Zawena.

Le respect de ces règles garantit une identité visuelle cohérente sur tous les supports de communication, qu'ils soient numériques ou imprimés.

Aucune version du logo ne doit être utilisée en dehors des recommandations définies dans ce document.

---

# 2. Philosophie du logo

Le logo de Zawena représente l'équilibre entre :

- l'innovation ;
- l'intelligence ;
- la technologie ;
- la confiance ;
- la simplicité.

Il a été conçu pour être :

- moderne ;
- intemporel ;
- facilement identifiable ;
- lisible à toutes les tailles ;
- adapté aussi bien au numérique qu'à l'impression.

Son design minimaliste reflète notre volonté de créer des technologies performantes sans complexité inutile.

---

# 3. Signification

Le logo est composé de deux éléments complémentaires.

## Le symbole

Le symbole représente l'interconnexion entre :

- les personnes ;
- les entreprises ;
- les données ;
- les logiciels ;
- l'Intelligence Artificielle.

Il évoque également :

- le mouvement ;
- l'évolution ;
- la croissance ;
- la collaboration.

Le symbole peut être utilisé seul lorsqu'il est suffisamment identifiable.

---

## Le logotype

Le mot « Zawena » constitue la signature principale de la marque.

Sa typographie moderne reflète :

- la stabilité ;
- la précision ;
- l'innovation.

Le logotype reste l'élément principal de reconnaissance de la marque.

---

# 4. Les versions officielles

Les versions autorisées sont les suivantes.

## Logo principal

Symbole + logotype.

Utilisation recommandée dans la majorité des cas.

---

## Logo horizontal

Version adaptée aux en-têtes de site web, signatures et documents.

---

## Logo vertical

Version adaptée aux affiches et présentations.

---

## Wordmark

Le mot « Zawena » seul.

Utilisation lorsque le symbole n'est pas nécessaire.

---

## Symbole seul

Le symbole graphique uniquement.

Réservé aux cas où la marque est déjà identifiée.

Exemples :

- favicon ;
- application mobile ;
- avatar de réseaux sociaux ;
- icône.

---

# 5. Construction du logo

Le logo a été conçu selon une grille simple garantissant :

- un équilibre visuel ;
- une bonne lisibilité ;
- une excellente reproductibilité.

Les proportions entre le symbole et le logotype ne doivent jamais être modifiées.

---

# 6. Zone de protection

Une zone de protection doit toujours être respectée autour du logo.

Cette zone garantit sa lisibilité.

La distance minimale correspond à la hauteur de la lettre **Z** du logotype.

Aucun élément graphique ou textuel ne doit pénétrer cette zone.

---

# 7. Taille minimale

Pour garantir la lisibilité :

## Numérique

Largeur minimale :

120 px

---

## Impression

Largeur minimale :

30 mm

En dessous de ces dimensions, utiliser uniquement le symbole.

---

# 8. Couleurs

Le logo utilise exclusivement les couleurs officielles de Zawena.

Aucune autre couleur ne doit être utilisée sans validation.

Les codes couleur sont définis dans :

`docs/brand/colors.md`

---

# 9. Utilisation sur différents fonds

## Fond clair

Utiliser la version officielle en couleurs.

---

## Fond sombre

Utiliser la version inversée prévue à cet effet.

---

## Fond photographique

Le logo doit toujours conserver un contraste suffisant.

Si nécessaire :

- utiliser une zone de protection ;
- ajouter un fond uni ;
- utiliser la version monochrome.

---

# 10. Versions monochromes

Deux versions monochromes sont autorisées.

## Noir

Pour les impressions monochromes.

---

## Blanc

Pour les fonds foncés.

Aucune autre variation monochrome n'est autorisée.

# 11. Utilisations interdites

Les modifications suivantes sont interdites.

❌ Modifier les couleurs.

❌ Déformer le logo.

❌ Changer la typographie.

❌ Ajouter des effets.

❌ Modifier les proportions.

❌ Tourner le logo.

❌ Ajouter un contour.

❌ Ajouter une ombre.

❌ Modifier l'espacement entre le symbole et le texte.

❌ Utiliser une version basse résolution.

❌ Recréer le logo manuellement.
