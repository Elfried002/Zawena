# 1. Objectif

Ce document définit les couleurs officielles de Zawena.

Il garantit une identité visuelle cohérente sur tous les supports :

- Site web
- Tableau de bord
- Applications SaaS
- Présentations
- Documents commerciaux
- Réseaux sociaux
- Supports imprimés

Toutes les interfaces développées par Zawena doivent respecter cette palette.

---

# 2. Philosophie des couleurs

Les couleurs de Zawena traduisent notre identité.

Nous souhaitons transmettre :

- la confiance ;
- l'innovation ;
- l'intelligence ;
- la sécurité ;
- la simplicité.

Notre palette est volontairement moderne, sobre et intemporelle.

Elle doit permettre de construire des interfaces élégantes, lisibles et professionnelles.

# 11. Accessibilité

Toutes les combinaisons de couleurs doivent respecter les critères WCAG.

Objectifs :

- contraste minimum AA ;
- lisibilité sur mobile ;
- compatibilité avec le mode sombre ;
- accessibilité pour les personnes atteintes de déficiences visuelles.

Les tests d'accessibilité doivent être réalisés avant toute mise en production.

---

# 12. Bonnes pratiques

Toujours :

- respecter la palette officielle ;
- conserver des contrastes suffisants ;
- utiliser les couleurs fonctionnelles pour les états système ;
- privilégier les couleurs neutres pour les arrière-plans.

Éviter :

- les couleurs non documentées ;
- les dégradés excessifs ;
- les interfaces trop colorées ;
- les combinaisons réduisant la lisibilité.
