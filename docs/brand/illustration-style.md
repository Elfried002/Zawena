# 1. Objectif

Ce document définit le style officiel des illustrations utilisées par Zawena.

Les illustrations contribuent à expliquer nos services, mettre en valeur notre expertise et renforcer l'identité visuelle de la marque.

Toutes les illustrations produites pour Zawena doivent respecter les principes définis dans ce document.

---

# 2. Philosophie des illustrations

Les illustrations de Zawena doivent représenter une technologie :

- moderne ;
- accessible ;
- intelligente ;
- humaine ;
- sécurisée.

Nous évitons les visuels trop abstraits ou trop complexes.

Chaque illustration doit raconter une idée claire.

---

# 3. Style visuel

Le style officiel de Zawena repose sur les principes suivants.

## Style principal

Illustrations vectorielles modernes.

---

## Apparence

Minimaliste.

---

## Géométrie

Formes simples.

Coins légèrement arrondis.

---

## Perspective

Légère perspective isométrique lorsque cela apporte une meilleure compréhension.

---

## Niveau de détail

Moyen.

Les illustrations doivent rester lisibles même à petite taille.

---

## Profondeur

Utilisation légère des ombres et des dégradés.

Éviter les effets réalistes.

---

## Ambiance

Professionnelle.

Innovante.

Optimiste.

Épurée.

---

# 4. Palette graphique

Toutes les illustrations utilisent exclusivement la palette officielle de Zawena.

Couleurs principales :

- Bleu Zawena
- Bleu foncé
- Violet IA
- Cyan
- Blanc
- Gris

Les couleurs secondaires servent uniquement à mettre en évidence certains éléments.

---

# 5. Éléments graphiques

Les illustrations peuvent intégrer :

- connexions réseau ;
- flux de données ;
- nœuds ;
- circuits ;
- interfaces utilisateur ;
- tableaux de bord ;
- nuages (Cloud) ;
- formes géométriques ;
- graphiques ;
- automations ;
- robots stylisés ;
- icônes technologiques.

Les éléments doivent rester sobres et cohérents.

# 7. Utilisation des illustrations

Les illustrations sont principalement utilisées sur :

- la page d'accueil ;
- les pages services ;
- les pages produits ;
- les pages "À propos" ;
- les études de cas ;
- les présentations ;
- les documents commerciaux.

Chaque illustration doit renforcer le message de la page.

---

# 8. Illustrations pour les interfaces

Les interfaces des applications Zawena utilisent des illustrations pour :

- les états vides ;
- les pages 404 ;
- les erreurs ;
- les confirmations ;
- les onboarding ;
- les tutoriels.

Ces illustrations doivent être simples et ne pas détourner l'attention des fonctionnalités principales.

---

# 9. Illustrations marketing

Les supports marketing peuvent utiliser des illustrations plus expressives tout en respectant l'identité visuelle.

Applications :

- site internet ;
- réseaux sociaux ;
- bannières ;
- brochures ;
- présentations ;
- publicités.

Les illustrations doivent toujours mettre en avant les bénéfices apportés par Zawena plutôt que la technologie elle-même.

---

# 10. Illustrations interdites

Ne jamais utiliser :

- des illustrations de faible qualité ;
- des styles cartoon ;
- des visuels surchargés ;
- des illustrations incohérentes avec la palette officielle ;
- des banques d'images génériques sans adaptation ;
- des éléments graphiques représentant des technologies obsolètes.

---

# 11. Bonnes pratiques

Toujours :

- respecter la palette officielle ;
- privilégier les formes simples ;
- conserver des proportions cohérentes ;
- utiliser les illustrations pour soutenir le contenu.

Les illustrations doivent compléter le message, jamais le remplacer.
