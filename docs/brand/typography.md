# 1. Objectif

Ce document définit les règles typographiques officielles de Zawena.

Il garantit une communication homogène sur tous les supports :

- Site internet
- Applications SaaS
- Tableau de bord
- Présentations
- Documentation
- Réseaux sociaux
- Documents commerciaux

---

# 2. Philosophie typographique

La typographie de Zawena doit refléter notre identité :

- moderne ;
- claire ;
- professionnelle ;
- élégante ;
- accessible.

Notre priorité est la lisibilité.

Une bonne typographie améliore l'expérience utilisateur et renforce la perception de qualité.

---

# 3. Police principale

## Inter

Inter est la police officielle de Zawena.

Elle est utilisée pour :

- le site web ;
- les tableaux de bord ;
- les interfaces SaaS ;
- la documentation ;
- les formulaires ;
- les emails.

### Raisons du choix

- excellente lisibilité ;
- optimisée pour les écrans ;
- open source ;
- largement adoptée ;
- nombreuses graisses disponibles.

---

# 4. Police secondaire

## Space Grotesk

Space Grotesk est utilisée pour :

- les titres marketing ;
- les pages d'accueil ;
- les campagnes ;
- les visuels de communication.

Elle apporte davantage de personnalité sans nuire à la cohérence de la marque.

# 7. Lisibilité

Afin de garantir une bonne expérience utilisateur :

- longueur de ligne recommandée : 60 à 80 caractères ;
- contraste conforme aux normes WCAG ;
- interligne suffisant ;
- espaces cohérents entre les titres et les paragraphes.

---

# 8. Bonnes pratiques

Toujours :

- respecter la hiérarchie des titres ;
- utiliser les graisses prévues ;
- conserver des espacements réguliers ;
- privilégier des paragraphes courts.

Les titres doivent être informatifs et concis.

---

# 9. Utilisations interdites

Ne jamais :

- utiliser plus de deux familles de polices ;
- modifier arbitrairement les tailles ;
- utiliser des effets décoratifs (ombre, contour, relief) ;
- écrire de longs paragraphes en majuscules ;
- réduire le contraste texte/fond.
