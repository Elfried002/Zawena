# 1. Objectif

Ce document définit l'univers visuel officiel de Zawena.

Il garantit que toutes les créations graphiques de l'entreprise partagent la même identité visuelle, quel que soit le support utilisé.

L'objectif est de construire une marque immédiatement reconnaissable.

---

# 2. Vision de l'univers visuel

L'univers visuel de Zawena repose sur quatre idées fondamentales.

• Intelligence

• Innovation

• Connexion

• Simplicité

Chaque visuel doit transmettre ces valeurs.

Notre identité graphique doit inspirer la confiance tout en évoquant la technologie moderne.

---

# 3. Les principes visuels

Toutes les créations graphiques doivent respecter les principes suivants.

## Clarté

Chaque visuel doit être immédiatement compréhensible.

Éviter les compositions trop chargées.

---

## Élégance

Nous privilégions un design minimaliste.

L'espace vide fait partie du design.

---

## Modernité

Les éléments graphiques doivent évoquer une entreprise tournée vers l'avenir.

---

## Cohérence

Toutes les créations doivent sembler appartenir à la même marque.

---

## Intemporalité

Nous évitons les effets de mode.

Notre identité doit rester pertinente pendant plusieurs années.

---

# 4. Les éléments graphiques

Les créations Zawena peuvent intégrer :

- réseaux de connexions ;
- lignes géométriques ;
- particules ;
- points ;
- flux de données ;
- formes abstraites ;
- interfaces utilisateur ;
- composants logiciels ;
- tableaux de bord ;
- éléments cloud.

Ces éléments doivent rester discrets.

Ils servent à renforcer le message.

---

# 5. Les textures

Les textures doivent être utilisées avec parcimonie.

Textures autorisées :

- dégradés doux ;
- verre (Glassmorphism léger) ;
- flou d'arrière-plan ;
- maillage géométrique ;
- trames discrètes.

Textures interdites :

- bruit excessif ;
- métal ;
- bois ;
- pierre ;
- textures réalistes.

---

# 6. Les formes

Les formes privilégiées sont :

- cercles ;
- rectangles arrondis ;
- lignes ;
- grilles ;
- nœuds ;
- arcs.

Les angles très agressifs sont à éviter.

Les formes doivent inspirer la fluidité.

---

# 7. Les effets

Les effets graphiques doivent rester subtils.

Autorisés :

- ombres légères ;
- transparence ;
- flou maîtrisé ;
- dégradés.

À éviter :

- biseaux ;
- reliefs ;
- effets 3D réalistes ;
- néons excessifs ;
- animations distrayantes.

---

# 8. Les compositions

Une composition Zawena doit privilégier :

- une hiérarchie claire ;
- un sujet principal ;
- des espaces respirants ;
- un équilibre visuel ;
- une lecture naturelle.

Les compositions doivent fonctionner aussi bien sur ordinateur que sur mobile.

---

# 9. Les éléments à éviter

Éviter :

- les banques d'images génériques sans personnalisation ;
- les illustrations incohérentes ;
- les palettes de couleurs non officielles ;
- les visuels surchargés ;
- les effets décoratifs inutiles ;
- les éléments graphiques contradictoires avec notre identité.

---

# 10. Bonnes pratiques

Toujours :

- utiliser la palette officielle ;
- respecter les règles de la charte graphique ;
- privilégier la simplicité ;
- mettre en avant le contenu avant les effets visuels.

L'univers graphique doit soutenir le message, jamais le remplacer.
