# 1. Objectif

Ce document définit le système officiel d'espacement utilisé dans tous les produits Zawena.

Son objectif est de garantir :

- une interface harmonieuse ;
- une excellente lisibilité ;
- une cohérence visuelle entre les différents produits ;
- une meilleure expérience utilisateur.

Toutes les interfaces doivent respecter ces règles.

---

# 2. Philosophie

Chez Zawena, les interfaces doivent respirer.

Nous privilégions :

- des espaces généreux ;
- une hiérarchie claire ;
- une grille cohérente ;
- des composants faciles à parcourir.

Nous utilisons un système basé sur une grille de **8 pixels**, largement adopté dans les Design Systems modernes.

---

# 3. Système d'espacement

Toutes les marges et tous les espacements sont dérivés des multiples de 8.

| Valeur | Taille |
|---------|--------:|
| XS | 4 px |
| SM | 8 px |
| MD | 16 px |
| LG | 24 px |
| XL | 32 px |
| 2XL | 40 px |
| 3XL | 48 px |
| 4XL | 64 px |
| 5XL | 80 px |
| 6XL | 96 px |

Les espacements intermédiaires (12 px, 20 px, etc.) ne sont utilisés que lorsque cela améliore réellement la lisibilité.

# 8. Rayons de bordure

Afin de conserver une identité homogène, les composants utilisent les rayons suivants.

| Élément | Rayon |
|----------|-------:|
| Bouton | 12 px |
| Carte | 16 px |
| Champ | 12 px |
| Badge | 9999 px |
| Modal | 20 px |
| Avatar | 9999 px |
| Tooltip | 10 px |

Les coins doivent rester légèrement arrondis afin de renforcer l'aspect moderne et accueillant de l'interface.

---

# 9. Ombres

Les ombres doivent rester discrètes.

## Small

Utilisée pour :

- champs
- boutons

---

## Medium

Utilisée pour :

- cartes
- menus

---

## Large

Utilisée pour :

- modales
- panneaux

---

Les ombres ne doivent jamais devenir un élément décoratif.

Elles servent uniquement à créer une hiérarchie visuelle.

---

# 10. Bonnes pratiques

Toujours :

- utiliser les espacements définis dans ce document ;
- conserver un rythme vertical régulier ;
- aligner les composants sur la grille ;
- privilégier la simplicité.

Éviter :

- les espacements arbitraires ;
- les composants trop rapprochés ;
- les interfaces surchargées ;
- les marges incohérentes.
